# LookMeNot Privacy Policy

Effective date: September 19, 2026

LookMeNot is an open-source browser extension that helps developers read Langfuse observability traces as a conversation.

## Data Processed

LookMeNot may process:

- Langfuse trace JSON visible on the active Langfuse page.
- Langfuse trace JSON returned to the active page by Langfuse network requests.
- JSON files or pasted JSON text provided by the user.
- Local reader preferences such as filter settings.

## How Data Is Used

The extension uses this data only to display trace messages, tool calls, tool results, and agent actions in the browser.

## Data Sharing

LookMeNot does not sell, rent, transfer, or share trace data with third parties.

LookMeNot does not send trace content to external servers.

LookMeNot does not use remote analytics.

## Storage

Trace data is held in browser memory while the pane is open. Reader preferences may be saved locally in the browser.

## Remote Code

LookMeNot does not execute remotely hosted code. The extension package includes its runtime code and assets.
